# ロボット走行シミュレーター

Arduinoコード自動変換対応の二輪ロボット走行シミュレーターです。

## GitHub Pages

このリポジトリの `index.html` を GitHub Pages で公開してください。

1. `Settings` → `Pages`
2. `Build and deployment` の `Source` を `Deploy from a branch`
3. Branch を `main`、フォルダを `/ (root)` にして `Save`

公開URL:
`https://yoko-05133.github.io/robot-simulator/`
